# Changelog: captionseasy-transcribe

## Unreleased

- No functional change since 0.1.0; not republished with captionseasy 0.2.0 (0.1.0 works with it). Hinglish creator
  spelling and Devanagari romanizing are applied by captionseasy itself (`settings.hinglishSpelling`,
  `settings.romanize`) on the words this add-on returns.

## 0.1.0

- First release: local Whisper speech-to-text with word timestamps (transformers.js + onnxruntime-node), models
  `en`, `hinglish`, `auto`; offline after the first model download. Existing look output: not applicable.
